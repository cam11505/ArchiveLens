`bundled_rar4_rar5_solid_encrypted_backend`. The approved provider/backend itself
is unchanged. Native source RAR tests and historical #44 Go evidence are separate.

## Reproduce and retain evidence

Local Windows check on 2026-09-28 (working development branch, not a release SHA):
Windows 11 build 22631 x64, Python 3.12.14, PySide6/Qt 6.11.2, Pillow 12.3.0.
Ruff/format passed, pytest **296 passed / 4 skipped**, source reader self-test
passed all 23 checks including native RAR and password PDF. Three skips were local
symlink-creation restrictions; one requires the dedicated mounted-volume lane.
These skips are not physical filesystem passes. Hosted final-commit results must
still be checked independently; local success is not a macOS result.

From the matching checkout with constrained dependencies, prepare the native RAR
backend, then run:

```text
python scripts/prepare_backends.py
python -m ruff check src tests scripts
python -m ruff format --check src tests scripts
python -m pytest -q --junitxml=outputs/source-regression/junit.xml
python -m archivelens --self-test-report outputs/source-regression/self-test.json
```

Use `QT_QPA_PLATFORM=offscreen` for automated source checks (PowerShell:
`$env:QT_QPA_PLATFORM='offscreen'`). Preserve skip reasons; a skipped case is not
a pass. New CI source artifacts are named
`ArchiveLens-source-regression-<runner-label>` and include JUnit, reader self-test
and non-sensitive generated state. Native package/installer/DMG evidence remains
in its separate platform lane. Verify final CI tested commit, downloaded DMG
SHA256SUMS and development manifest; artifact ZIP-wrapper hashes are different.
